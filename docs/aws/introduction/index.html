Introduction to AWS

What is AWS?​

  • Amazon Web Services (AWS) is a comprehensive cloud computing platform
  • Offers 200+ fully featured services from data centers globally
  • Pay-as-you-go pricing model
  • Used by millions of customers including startups, enterprises, and government agencies

Key AWS Services Overview​

  • Compute (EC2, Lambda)
  • Storage (S3, EBS)
  • Databases (RDS, DynamoDB)
  • Networking (VPC, Route53)
  • Security (IAM, KMS)
  • Analytics (Redshift, EMR)
  • AI/ML (SageMaker, Rekognition)

AWS Global Infrastructure​

Regions​

  • Geographically isolated areas
  • Each region contains multiple Availability Zones
  • Independent power, cooling, and physical security

Availability Zones (AZs)​

  • One or more discrete data centers
  • Connected through low-latency links
  • Designed for fault isolation

Edge Locations​

  • Content delivery network (CloudFront) endpoints
  • Used for caching content
  • Located in major cities worldwide
